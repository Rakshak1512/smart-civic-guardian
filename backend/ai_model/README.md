# Smart Civic Guardian - AI image classifier

The application uses a frozen MobileNetV2 feature extractor and a trained
logistic-regression classifier to classify civic issue photographs into:

- Garbage
- Pothole
- Water Leakage
- Electricity Issue

The inference path is in \`predict.py\`. The feature extractor and pretrained
backbone weights are in \`backbone.py\` and \`model/\`.

## Accuracy and dataset limitations

The checked-in dataset is imbalanced: the repository currently has many more
Garbage photographs than Pothole, Water Leakage and Electricity Issue
photographs. Balanced class weights help with unequal counts, but cannot
replace missing real-world variety. Water Leakage was the weakest class in the
previous saved evaluation report.

The previous \`training_report.json\` was generated by an older validation
pipeline. Retraining with the updated \`train.py\` regenerates it using
stratified grouped cross-validation. Exact and near-duplicate images remain in
the same fold, all augmentations from a photo stay in that photo's fold, and
cross-image synthetic composites are disabled to prevent validation-scene
leakage.

Grouped cross-validation on training data is not a guarantee of performance on
new street photographs. An independent test set is required to estimate
real-world accuracy.

## Retrain

From the repository root:

\`\`\`bash
python -m pip install -r backend/ai_model/requirements.txt
python backend/ai_model/train.py
\`\`\`

This updates \`model/civic_classifier.npz\`, \`model/labels.json\` and
\`model/training_report.json\`. The report contains current source-image
counts, per-class precision/recall/F1, confusion matrix, duplicate-group
counts, fold metrics and the selected regularization value.

## Independent evaluation

Prepare a separate directory of real photographs that were not used for
training, with one folder per category:

\`\`\`
held_out_dataset/
  Garbage/
  Pothole/
  Water_Leakage/
  Electricity_Issue/
\`\`\`

Run:

\`\`\`bash
python backend/ai_model/evaluate.py --dataset path/to/held_out_dataset
\`\`\`

The evaluator rejects exact file duplicates of training images and writes an
independent report containing accuracy, macro precision, macro recall, macro
F1, per-class metrics, confusion matrix and mistakes.

Use photos from different locations, devices, lighting, distances, weather
conditions and camera angles. Keep the external test set separate; do not move
it into the training folders after inspecting the scores.

## Automated retraining

The GitHub Actions workflow
\`.github/workflows/retrain-civic-model.yml\` retrains the model when the
training code or dataset changes on the accuracy-improvement branch. It then
commits the generated model weights and report back to that branch. It can
also be started manually from GitHub Actions.
